# The Road Is Life

This repository keeps the recovered source material separate from the Hugo site:

- [`extraction/`](extraction/README.md) contains the Python recovery tools, raw
  Wayback responses, extracted Markdown, and recovered images.
- [`blog/`](blog/README.md) is the Hugo site project and GitHub Pages build source.
- [`TODO.md`](TODO.md) tracks recovery gaps and the site work.

The static site is built from the Markdown and photos in `extraction/`; it does
not publish the raw capture archive.
